# Matplotlib

> The foundational Python plotting library — figures, axes, charts, and publication-ready visuals.

**Prerequisites:** [NumPy](../numpy/README.md)  
**Part of:** [Python Frameworks & Libraries](../README.md)

---

## Definition

**Matplotlib** is a 2D plotting library. The central objects are **`Figure`** (canvas) and **`Axes`** (a single plot area). The `pyplot` interface (`plt`) is a convenient state-based API; the object-oriented API is preferred for complex layouts.

---

## When to use Matplotlib

| Use | Example |
|-----|---------|
| Metric curves | loss / accuracy over steps |
| Distributions | score histograms |
| Comparisons | bar charts by model |
| Matrices | confusion / attention heatmaps |
