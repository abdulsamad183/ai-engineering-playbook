# 7. Multitask Learning

> Shared backbone, multiple heads — transfer across related objectives.

## Definition

**Multitask learning** trains one model on several tasks at once, sharing representations when tasks help each other.

## Tips

- Balance loss weights  
- Watch negative transfer  
- Prefer related task families
