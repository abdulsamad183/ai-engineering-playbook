# 6. Self-Supervised Learning

> Labels from the data itself — masked prediction, contrastive views, and more.

## Definition

**Self-supervised learning (SSL)** creates pretext tasks from unlabeled data (mask tokens, augment views) to learn transferable representations.

## Families

| Family | Examples |
|--------|----------|
| Predictive | MLM, next-token |
| Contrastive | SimCLR, CLIP-style |
| Masked autoencoding | MAE, BERT
