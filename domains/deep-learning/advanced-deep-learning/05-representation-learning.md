# 5. Representation Learning

> Learn embeddings that make downstream tasks easier.

## Definition

**Representation learning** seeks features/latents where semantics are easier to separate or retrieve — the point of deep stacks and pretraining.

## Examples

- ImageNet backbones  
- Word/sentence embeddings  
- Contrastive SSL features
