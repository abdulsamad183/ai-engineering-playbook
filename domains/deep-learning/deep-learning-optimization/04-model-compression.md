# 4. Model Compression

> Shrink models for cheaper inference — distill, quantize, prune.

## Definition

**Model compression** reduces size/latency while preserving enough quality for deployment constraints.

## Techniques

- Knowledge distillation  
- Quantization  
- Pruning / sparsity  
- Smaller architectures / adapters
