# 5. CNN Architectures

> Landmark families — VGG, ResNet, EfficientNet, ConvNeXt.

## Definition

**CNN architectures** package conv blocks into proven topologies for ImageNet-scale learning and transfer.

## Families (know the names)

| Family | Idea |
|--------|------|
| VGG | Deep stacks of small convs |
| ResNet | Residual blocks |
| EfficientNet | Compound scaling |
| ConvNeXt | Modernized conv design |

## Practice

- Start from a pretrained backbone for most vision tasks
