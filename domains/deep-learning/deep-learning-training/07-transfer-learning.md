# 7. Transfer Learning

> Start from pretrained weights — the default path for vision and NLP.

## Definition

Reuse a model trained on a related large task, then adapt to your data. Cuts data/compute needs dramatically.

## Checklist

1. Load pretrained backbone  
2. Replace task head  
3. Choose freeze vs fine-tune  
4. Use a smaller LR on pretrained layers
