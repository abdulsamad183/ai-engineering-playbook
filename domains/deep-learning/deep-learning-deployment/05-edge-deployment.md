# 5. Edge Deployment

> Run on-device — mobile NPUs, IoT constraints, and offline inference.

## Definition

**Edge deployment** places models on devices (phones, gateways, MCUs) with tight memory, power, and connectivity limits.

## Implications

- Strong need for compression/quantization  
- Offline eval on target hardware  
- Careful update/rollback story
