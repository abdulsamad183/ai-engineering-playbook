# 4. TensorRT

> NVIDIA inference optimizer — engines tuned for GPU latency/throughput.

## Definition

**TensorRT** builds optimized GPU inference engines (fusion, precision calendars, tactics) from ONNX/networks.

## When

- NVIDIA GPUs in production  
- Hard latency SLOs after a stable ONNX export
