# 5. Error Analysis

> Slice failures — confusion patterns, hard cohorts, and label issues.

## Definition

**Error analysis** inspects where the model fails (by class, length, domain slice) to guide data and modeling fixes.

## Practice

1. Sample false positives/negatives  
2. Group by failure mode  
3. Fix data/labels or add features/capacity intentionally
