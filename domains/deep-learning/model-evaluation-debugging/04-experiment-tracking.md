# 4. Experiment Tracking

> Log metrics, configs, and artifacts — W&B, MLflow, TensorBoard.

## Definition

**Experiment tracking** records hyperparameters, metrics, and artifacts so runs are comparable and reproducible.

## Tools

| Tool | Notes |
|------|-------|
| TensorBoard | Local curves |
| W&B / MLflow | Hosted/collaborative tracking |
| CSV / JSONL | Minimal custom logs |

## Tip

- Log LR, batch size, seed, git commit, data version
