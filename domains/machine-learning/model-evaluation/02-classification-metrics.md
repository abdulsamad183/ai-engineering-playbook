# 2. Classification Metrics

> Accuracy is not enough — choose metrics for the decision cost.

## Definition

**Classification metrics** summarize correctness of labels or ranking quality of scores.

## Starter set

| Metric | Use when |
|--------|----------|
| Accuracy | Balanced classes, equal costs |
| Precision / Recall / F1 | Imbalance or asymmetric costs |
| ROC-AUC | Ranking quality |
| Log-loss | Probabilistic quality |
