# 6. Dimensionality Reduction

> Compress features — speed, noise reduction, and visualization.

## Definition

**Dimensionality reduction** maps high-d data to fewer dimensions while preserving structure (variance, distances, or neighborhoods).

## Families

| Family | Examples |
|--------|----------|
| Linear | PCA, SVD |
| Manifold / nonlinear | t-SNE, UMAP, Isomap |
| Feature selection | Keep original axes (different section) |

## Uses

- Visualization (2D/3D)  
- Preprocessing before clustering / classical models  
- Noise reduction
