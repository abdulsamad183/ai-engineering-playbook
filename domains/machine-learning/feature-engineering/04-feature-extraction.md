# 4. Feature Extraction

> Create new features from raw inputs — PCA, text, time, aggregations.

## Definition

**Feature extraction** builds derived signals: embeddings, PCA components, TF-IDF, window aggregates, domain formulas.

## Examples

| Domain | Extracted features |
|--------|--------------------|
| Text | TF-IDF, embeddings |
| Time series | lags, rolling mean |
| Tables | ratios, group aggregates |
| Images | CNN embeddings (DL) |
