# 6. Explainable AI

> Why the model said that — global and local explanation methods.

## Definition

**Explainable AI (XAI)** produces human-understandable reasons for model behavior: feature attributions, rules, counterfactuals, and example-based explanations.

## Methods

| Method | Scope |
|--------|-------|
| Coefficients / trees | Intrinsic |
| Permutation importance | Global |
| SHAP / LIME | Local (and global aggregates) |
| Partial dependence | Global marginal effect |

## Uses

- Regulated decisions  
- Debugging data leakage  
- Building trust with stakeholders
