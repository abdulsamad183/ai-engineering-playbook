# 2. Recommendation Systems

> Suggest items — collaborative filtering, content features, and ranking metrics.

## Definition

**Recommenders** rank items for users using interactions (collaborative), item/user features (content), or hybrids.

## Families

| Family | Idea |
|--------|------|
| Collaborative | Users like me liked X |
| Content-based | Items similar to what you liked |
| Two-tower / embeddings | Learn user & item vectors |
| Ranking | Learn-to-rank on candidates |

## Metrics

- Precision@k, Recall@k, NDCG, MAP  
- Beyond accuracy: diversity, cold-start
