# 2. Text Representation

> From characters to vectors — how text becomes model input.

## Definition

**Text representation** maps language into symbols or vectors models can consume: tokens, sparse counts, dense embeddings, or contextual hidden states.

## Ladder

| Level | Examples |
|-------|----------|
| Symbolic | tokens, POS tags |
| Sparse | BoW, TF-IDF |
| Static dense | Word2Vec, GloVe |
| Contextual | BERT/GPT hidden states |
