# 3. Text Preprocessing

> Clean and structure raw text before modeling.

## Definition

**Preprocessing** turns messy raw text into consistent inputs: encoding fixes, noise removal, normalization, and segmentation.

## Typical steps

1. Decode / fix encoding  
2. Lowercase (task-dependent)  
3. Strip HTML / boilerplate  
4. Normalize whitespace & unicode  
5. Tokenize for the model  

## Tip

- Match train and production preprocessing exactly
