# 2. N-Grams

> Local token sequences — unigrams, bigrams, trigrams as features.

## Definition

An **n-gram** is n consecutive tokens. Captures short phrases beyond pure BoW unigrams.

## Tradeoff

- Higher n → more context, sparser features
