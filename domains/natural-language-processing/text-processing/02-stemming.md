# 2. Stemming

> Crude root cutting — fast but rough morphological reduction.

## Definition

**Stemming** chops word endings with heuristic rules (e.g. Porter) to map related forms to a stem (`studies` → `studi`).

## When

- Classic sparse IR / keyword features  
- Prefer lemmatization when linguistic accuracy matters
