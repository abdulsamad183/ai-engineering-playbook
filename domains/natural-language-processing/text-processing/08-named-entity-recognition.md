# 8. Named Entity Recognition

> Find people, orgs, places, and custom entities in text.

## Definition

**NER** spans and types entities in text. Classic CRF/HMM → BiLSTM-CRF → transformer token classification.

## Evaluation

- Prefer span-level F1, not token accuracy alone
