# 7. Part-of-Speech Tagging

> Label tokens as noun/verb/adj — structure for classic pipelines.

## Definition

**POS tagging** assigns grammatical categories to tokens. Useful for classical features, lemmatization, and linguistics-aware rules.

## Modern note

- End-to-end transformers often skip explicit POS, but tags still help hybrid systems
