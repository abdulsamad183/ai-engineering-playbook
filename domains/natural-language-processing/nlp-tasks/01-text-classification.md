# 1. Text Classification

> Assign labels to documents or sentences — topic, intent, toxicity.

## Definition

**Text classification** maps text to discrete classes. Methods: TF-IDF + linear models → fine-tuned encoders → LLM classifiers.

## Metrics

- Accuracy / F1 / PR-AUC depending on imbalance
