# 3. Text Similarity

> Score relatedness — lexical overlap vs embedding cosine.

## Definition

**Text similarity** measures how close two strings are (duplicate detection, retrieval, clustering).

## Approaches

| Approach | Notes |
|----------|-------|
| Jaccard / edit distance | Lexical |
| TF-IDF cosine | Sparse semantic-ish |
| Embedding cosine | Dense semantic |
