# 1. Tokenization

> Map text ↔ token IDs with a model-specific vocabulary.

## Definition

**Tokenization** is the reversible-ish mapping between raw text and integer token IDs the model embeds.

## Rule

- Always use the tokenizer that matches the checkpoint
