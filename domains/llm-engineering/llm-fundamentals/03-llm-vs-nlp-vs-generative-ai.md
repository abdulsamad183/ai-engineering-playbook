# 3. LLM vs NLP vs Generative AI

> How the terms overlap — and when to use each precisely.

## Definitions

| Term | Scope |
|------|-------|
| NLP | Field of language tech (classic + neural) |
| Generative AI | Models that create content (text, image, audio…) |
| LLM | Large generative language models (subset of both) |

## Tip

- Not all NLP is generative; not all GenAI is language
